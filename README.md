# 🇬🇧 English Learning Bot

Telegram-бот для эффективного запоминания английских слов. Бот предлагает случайные слова для перевода, проверяет ответы пользователя с учетом возможных опечаток (fuzzy matching) и ведет статистику взаимодействий.

> 💡 *Проект создан как часть практики в Python Backend разработке и работе с асинхронными фреймворками.*

## ✨ Возможности

- 🎲 **Случайная выборка**: бот предлагает слова из заранее подготовленного словаря (`words.json`).
- 🧠 **Умная проверка ответов**: использование алгоритма сравнения строк с порогом схожести (threshold = 0.8), чтобы засчитывать ответы с незначительными опечатками.
- ⏭️ **Функция пропуска**: возможность пропустить слово через команду `/skip` или инлайн-кнопку с показом правильного ответа.
- 🗄️ **Хранение состояния**: использование FSM (Finite State Machine) из `aiogram 3.x` и `SQLite` для сохранения прогресса и состояния диалога.
- 📝 **Детальное логирование**: запись действий пользователей и ошибок в файл для мониторинга и отладки.

## 🛠️ Технологический стек

- **Язык**: Python 3.10+
- **Фреймворк**: [aiogram 3.x](https://docs.aiogram.dev/) (асинхронный Telegram Bot API)
- **Хранилище**: SQLite (через `aiogram_sqlite_storage`)
- **Конфигурация**: вынесена в `config.py` (рекомендуется использование `.env` и `pydantic` для валидации)
- **Алгоритмы**: нормализация строк и расчет коэффициента схожести (ratio) для обработки опечаток.

## 📁 Структура проекта

```text
.
├── main.py            # Точка входа: инициализация бота, диспетчера и polling

```

## 🚀 Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/utyara3/english_bot.git
   cd english_bot
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Windows: venv\Scripts\activate
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Настройте конфигурацию:
   Создайте файл `.env` и укажите ваш Telegram Bot Token:
   ```env
   BOT_TOKEN=your_telegram_bot_token_here
   ```

5. Запустите бота:
   ```bash
   python main.py
   ```
